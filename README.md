# Praveen Singh — Portfolio

A responsive React portfolio based on the selected charcoal-and-lime design. Built with React, Vite, Inter, and Phosphor icons.

## Development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
```

Static output is in `dist/client`. The starter also produces a compatible Worker in `dist/server` for optional Sites hosting. No backend, API keys, or database are required.

Content and the Upwork profile URL live in `src/App.jsx`. Responsive layouts and colors live in `src/styles.css`.

The healthcare preview is illustrative artwork cropped from the selected design. It contains synthetic sample data, not patient data or an actual client screenshot. The project description states a contribution, not ownership. The About section was added so navigation has a useful destination.

Navigation, service links, mobile menu, and contact buttons work. This repository does not publish a website automatically.
